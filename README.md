# Muxly                                                

Native tmux for iPhone and iPad.                       

Muxly is an SSH terminal for iPhone and iPad built around tmux control mode. It presents tmux windows as native tabs (think iTerm2 on macOS), and panes through a pane picker on iPhone and following their tmux layout on iPad. tmux stays the source of truth. Work keeps running when iOS suspends the connection, and Muxly reconnects and reattaches when you return. You can enable push notifications to let terminal bells reach you while disconnected.

- Docs: https://muxly.sh/docs
- Guides: https://muxly.sh/guides

Muxly is not open source. For support, email support@muxly.sh or see https://muxly.sh/support.

## Requirements

- iOS or iPadOS 18 or later
- tmux 3.2 or later on the server for native tmux integration; plain SSH works without tmux
