# Muxly                                                

Native tmux for iPhone and iPad, built for AI coding agents running on your host.

Muxly is an SSH terminal for iPhone and iPad built around tmux control mode. It presents tmux windows as native tabs (think iTerm2 on macOS), and panes through a pane picker on iPhone and following their tmux layout on iPad. tmux stays the source of truth. Your agents keep running on your host even when you close the app or lose your connection. Muxly notifies you when they finish or need input.

Muxly is not open source. For support, email support@muxly.sh or see https://muxly.sh/support.

## Requirements

- iOS or iPadOS 18 or later
- tmux 3.2 or later on the server for native tmux integration; plain SSH works without tmux
